# Candidate Web3 Task

This project focuses on building a DeFi-style protected ERC20 token transfer application using Solidity, Hardhat, MetaMask, and React. The solution includes smart contract development, wallet integration, secure token transfers, and a responsive frontend connected to a locally deployed ERC20 token.

The app should run locally at:

```bash
http://localhost:3000/
```

## Quick start

Install dependencies first:

```bash
npm install
```

Start the local blockchain:

```bash
npm run dev:chain
```

In another terminal, deploy the contracts:

```bash
npm run deploy:local
```

Start the frontend:

```bash
npm run dev:frontend
```

Run contract tests:

```bash
npm run test:contracts
```
